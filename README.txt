THE GOOB LEDGER — GIBLETISM POINTS & RANK TRACKER

QUICK START
1. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
2. Add members, award or deduct points, and choose the date for each point event.
3. Use Point Rules to create named awards and deductions with your own point values. Select Apply on a rule to record it for a member and date.
4. Use Hierarchy Settings to change titles and the lifetime points required for each rank.

DATA & PRIVACY
- Your roster, points, point rules, and rank settings are saved in this browser's local storage.
- No account or external server is used.
- The data does not automatically sync between devices or browsers.
- Use Export Backup regularly to save a JSON copy; use Import Backup to restore it.
- Avoid entering sensitive personal information. Use names/nicknames with participants' agreement.

PUBLISH AS A WEBSITE (GITHUB PAGES)
1. Create a new GitHub repository.
2. Upload all files in this folder (index.html, manifest.webmanifest, sw.js, icon.svg, icon-192.png, icon-512.png).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), then Save.
5. Open the published GitHub Pages URL. The site can be installed from a supported browser's install option and works offline after its first load.

NOTE
Opening index.html directly works for normal use. Service-worker offline caching and installable-app features require hosting over HTTPS (such as GitHub Pages) or localhost.
